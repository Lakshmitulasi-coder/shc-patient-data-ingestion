Fault Tolerance Policies:

  • • HTTP 400 Bad Request: Non-retriable. Automatically dumped to failed_records.json with payload and error details. The pipeline continues uninterrupted for the next batch.
  • • HTTP 429 Rate Limited: Reads Retry-After header if provided by server; otherwise falls back to exponential backoff ($1.0s \times 2^{(\text{attempt}-1)} + \text{jitter}$).
  • • Credential Masking: Sensitive Bearer tokens are masked in all logs (mo****-xyz) to maintain security compliance.
  • • RFC 4180 Heuristic Recovery: Detects unquoted commas in balance when row has exactly 1 extra column and valid timestamp, safely reconstructing float value.
